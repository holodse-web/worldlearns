## Готовые материалы

- Название: **World Learns**. Без версии, «beta», загрузчика и рекламных дополнений в названии проекта.
- Короткое описание: английский абзац из `SHORT_DESCRIPTIONS.md`. Он без форматирования и повторения названия; русский вариант сохранён отдельно.
- Основное описание: содержимое `MODRINTH_DESCRIPTION.md` в формате Markdown.
- Лицензия: **All Rights Reserved**, как в существующем `fabric.mod.json` и корневом `LICENSE`.
- Каждую сборку публиковать как **Beta**, с соответствующей версией Minecraft и загрузчиком **Fabric**. Не загружать JAR для разных версий игры как «дополнительные файлы» одного релиза.
- Для каждой версии добавить **Fabric API** в обязательные Dependencies и проверить требования её JAR. Таблица Java/Loader/API есть в README.
- Для полного опыта рекомендована установка на клиент и сервер. Выделенный сервер и смешанные клиенты ещё требуют игровой проверки; не заявлять их проверенную совместимость.
- Пока GitHub приватный, не указывать его в публичных Source/Issues ссылках страницы: правила требуют публичных релевантных ресурсов. Ссылку на исходники добавлять после открытия репозитория.

## Раскрытие использования ИИ

Описание и краткие тексты написаны с помощью генеративного ИИ. При использовании этих материалов нужно отметить **AI-generated text** в Content Disclosures.

В коде также есть необязательная генерация реплик жителей через внешний или локальный endpoint. Поэтому отметить **Generative AI functionality** (в справке — AI functionality); она выключена по умолчанию. В основном описании уже раскрыто, какие сообщения и контекст отправляются при включении. Для удалённого сервиса проверить применимость **Contains Telemetry / Opt-in** по его фактическому хранению и обработке данных и дать соответствующие публичные сведения о конфиденциальности. Согласие оператора на сервере само по себе не подтверждает согласие каждого игрока.

Отдельно проверить реальное происхождение кода, текстов и ассетов:

- При значительном объёме сгенерированного кода требуется **AI-generated code**.
- При распространяемых ИИ-ассетах требуется **AI-generated assets**.
- ИИ-изображения запрещены в иконке проекта, галерее, описании и других частях страницы, даже при раскрытии ИИ.
- Полностью или преимущественно созданные ИИ проекты нельзя публиковать публично. Простое составление запросов и тестирование не заменяет существенный человеческий вклад. Руководство упоминает возможность unlisted для многих таких проектов; это не гарантия одобрения.

Эта проверка не устанавливала долю человеческого/ИИ-кода или происхождение логотипа. Не скрывать эти сведения. Обычная игровая логика мобов и поиск пути сами по себе не означают генеративный ИИ.

# Перенос World Learns на другие версии Minecraft (Fabric)

Основной проект — 26.3 (папка `src`). Версии 1.21.4, 1.21.1 и 1.20.1 не правятся руками отдельно,
а собираются из исходников 26.3:

1. `pipeline.sh <версия> <корень проекта> <папка>` копирует `src` и прогоняет автозамены из `codemod/`
   (to1214 → to1214b → to1211 → to1201/to1201b/to1201data, по цепочке для нужной версии).
2. Поверх накладывается `patches/patch-<версия>.diff` — ручные правки, которые не делаются автозаменой
   (сеть для 1.20.1, фон экранов, правила мира, совместимость атрибутов и т. п.).
3. `build-port.sh <версия>` делает оба шага, компилирует против Minecraft с именами Mojang и
   переименовывает результат в intermediary (MapTool + tiny-remapper), получается обычный jar для Fabric.

Если патч перестал накладываться после изменений в 26.3, правим получившиеся исходники
в рабочей папке, собираем, и заново снимаем патч:
`diff -ruN a/src b/src > patches/patch-<версия>.diff` (a — результат pipeline, b — исправленная версия).

Окружение для сборки (Minecraft, карты имён, Fabric API) лежит в архивах
`.devcache/port-1.21.4.zip` и `.devcache/port-old.zip`, разворачивается `setup_env_old.sh`.
